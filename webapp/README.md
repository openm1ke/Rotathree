# Rotathree — веб-версия

Та же игра, что и во Flutter-проекте уровнем выше, для браузера и клавиатуры.

Играть: https://openm1ke.github.io/Rotathree/ — страница собирается из этой
папки и публикуется через GitHub Actions (`.github/workflows/pages.yml`) при
каждом пуше в `main`, который её затрагивает.

Стек такой же, как у веб-порта RuneChess: **Vite + TypeScript + React**, тесты —
**Vitest**. Игровой движок в `src/game` — чистый TypeScript без React и DOM,
построчный порт `lib/game` из Flutter-проекта.

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Откроется на `http://localhost:5183`.

## Проверки

```bash
npm run check
```

Это `typecheck` + `lint` + `test` + `build` подряд.

## Режимы

- **Играть** — одна партия на выживание.
- **Дзен** — та же игра по уровням: набрали очки уровня (1000, 1500, 2000 …) —
  короткая анимация и пауза, затем игра продолжается с того же места. Скорость
  не растёт. Если стакан переполнился, предлагается начать заново с первого
  уровня.

## Управление

Клавиши по умолчанию (меняются в «Настройки → Управление», привязка идёт к
физической клавише, поэтому раскладка не важна):

| Действие | Клавиши |
|---|---|
| Сдвиг фигуры | ← → |
| Поворот по часовой / против | ↑ или X / Z |
| Мягкий сброс (держать) | ↓ |
| Сброс | Пробел |
| Стакан слева / справа / напротив | A / D / S |
| Пауза | Esc или P |
| Заново | R |

Удержание ← → повторяет сдвиг: задержка (DAS) и интервал (ARR) настраиваются.
Клик по рукаву мышью тоже поднимает этот стакан наверх.

## Структура

```
src/
  game/        движок: config, board, glass, piece, placement, matchDetector,
               gravity, cascade, generator, incoming, engine; zen — уровни дзена
  render/      canvas: renderer (поле, блоки), effects (толчки, частицы), theme
  input/       bindings (привязки клавиш), keyboard (автоповтор DAS/ARR)
  services/    settingsStore (localStorage)
  components/  MenuScreen, GameScreen, Hud, SettingsPanel
  styles/      tokens.css, global.css
  tests/       model, engine, input, effects, zen
```

## Настройки

Три вкладки, всё применяется сразу:

- **Управление** — клавиши (по два слота на действие) и автоповтор.
- **Игра** — шаг падения в активном и в остальных стаканах, длина рукава,
  число дополнительных стаканов (1–3: всего в игре 2, 3 или 4 стакана), число
  цветов (3–6), варианты правил. Смена любого пункта начинает новую партию.
- **Интерфейс** — длительность поворота поля (0–600 мс, 0 — мгновенно), тряска,
  показывать ли подсказки клавиш, очки с комбо и остальную статистику,
  непрозрачность надписей.

Настройки хранятся в `localStorage` под ключом `rotathree.settings.v1` и
остаются после закрытия вкладки. В приватном режиме браузер может их не
сохранять — тогда панель настроек об этом пишет.
